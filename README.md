# GLYCO-01 | Clinical Data Management Project

## Project Overview
This project demonstrates clinical data management, data cleaning, validation, SQL analysis, and Power BI reporting using a synthetic Type 2 diabetes clinical trial dataset.

## Dataset Details
- **Study:** GLYCO-01
- **Total Subjects:** 150
- **Total Visit Records:** 600
- **Study Visits:** Baseline, Week 4, Week 8, Week 12
- **Treatment Groups:** Placebo, DrugX 5 mg, DrugX 10 mg
- **Tools:** Microsoft Excel, MySQL, Power BI

## Project Workflow

### 1. Excel — Data Cleaning and Validation
- Removed duplicate records.
- Checked missing and invalid values.
- Validated subject information and visit dates.
- Reviewed protocol deviations and adverse event data.
- Maintained a data query log.

### 2. MySQL — Clinical Data Analysis
- Imported and verified 600 clinical visit records.
- Analyzed treatment groups and visit distribution.
- Calculated HbA1c summaries.
- Analyzed adverse event frequencies and serious adverse event flags.
- Identified missing data and records pending review.

### 3. Power BI — Dashboard Development
Created an interactive dashboard displaying subject enrollment, visit records, treatment groups, HbA1c trends, adverse event frequencies, and data quality indicators.

## Key Data Quality Findings
- **Missing HbA1c values:** 8
- **Missing visit dates:** 5
- **Records pending review:** 47

## Skills Demonstrated
Clinical Data Management, Data Validation, Data Cleaning, Discrepancy Identification, Query Management, SQL, Excel, DAX, and Power BI.

## Disclaimer
This project uses synthetic data for educational and portfolio purposes. It does not represent an actual clinical trial. Adverse event record counts are not necessarily unique adverse event episodes.
